# 🏢 TatvaSoft 15-Day Summer Internship – 2025

This repository contains the complete project developed during my 15-day virtual summer internship at **TatvaSoft**. The project is a full-stack web application built using **Angular 14**, **.NET 8 Web API**, and **PostgreSQL**, following modern development practices.

## 🚀 Tech Stack

- **Frontend**: Angular 14
- **Backend**: .NET 8 Web API (C#)
- **Database**: PostgreSQL with pgAdmin
- **Tools**: Visual Studio 2022, Visual Studio Code
- **Deployment**: AWS (Basics covered)

---

## 🛠️ Setup Instructions

Ensure the following are installed:

- Node.js (LTS) & Angular CLI 14 → https://nodejs.org/
- .NET 8 SDK → https://dotnet.microsoft.com/download/dotnet/
- PostgreSQL & pgAdmin → https://www.postgresql.org/download/
- Visual Studio 2022 → https://visualstudio.microsoft.com/downloads/
- Visual Studio Code (optional) → https://code.visualstudio.com/

📄 Refer to the `Prerequisite.pdf` file in this repository for complete installation guidance.
